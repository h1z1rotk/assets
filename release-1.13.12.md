# Weapon Stance PS3 and ROTK Bindings

Requires the prepared ROTK Launcher 2.0.16 native patch.

- Add ROTK Bindings with Weapon Stance (PS3) and Console shortcuts.
- Default stance key V; default console key N; both can be rebound.
- Restore the validated PS3 stance animation graph with smooth idle blending.
- Preserve every other asset in the current published packs and all unrelated
  menu, rank, voice, cosmetic and gameplay updates.

Changed installed files: assets_x64_0.pack2, assets_x64_10.pack2,
data_x64_0.pack2, the eleven locale pairs and InputProfile_Default.xml.
The default profile appends the custom actions after the stock actions; it
leaves native ToggleDebugConsole unchanged. InputProfile_User.xml is never
distributed as an asset.

Publication is coordinated with the launcher and server integrity policy.
The prepared higher-version rollback restores the previous payload bytes.
